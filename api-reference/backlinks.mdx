---
title: "Backlinks"
description: "Manage backlink campaigns, opportunities, and outreach email generation and sending."
---

Run backlink research campaigns, manage opportunities discovered for each campaign, and generate or send personalized outreach emails.

**Base URL**: `https://app.keupera.com/api/v1`

## List campaigns

```http
GET /campaigns
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `website_id` | UUID | Target website |

### Response

```json
{
  "data": [
    {
      "id": "uuid",
      "keyword": "seo tools",
      "niche": "Digital Marketing",
      "status": "active",
      "language": "en",
      "target_domain": "example.com",
      "is_public": false,
      "public_share_token": null,
      "progress": null,
      "general_strategies": [],
      "websites": { "url": "https://example.com" },
      "created_at": "2024-01-15T10:00:00Z"
    }
  ]
}
```

## Create campaign

```http
POST /campaigns
```

### Request body

```json
{
  "website_id": "uuid",
  "keyword": "seo tools",
  "niche": "Digital Marketing",
  "language": "en",
  "target_domain": "myblog.com"
}
```

| Field | Required | Description |
|-------|----------|-------------|
| `keyword` | Yes | Target keyword for backlink research |
| `niche` | Yes | Industry/niche context |
| `language` | No | Language code (defaults to website language) |
| `target_domain` | No | Domain to research backlinks for. Defaults to the website's own domain. Useful when you want to find backlink opportunities for a domain different from your tracked website (e.g. a subdomain or partner site). |

### Response (201)

```json
{
  "data": {
    "id": "uuid",
    "keyword": "seo tools",
    "niche": "Digital Marketing",
    "target_domain": "myblog.com",
    "status": "active",
    "language": "en",
    "is_public": false,
    "public_share_token": null
  }
}
```

<Note>
  Backlink opportunity research is automatically triggered in the background once a campaign is created.
</Note>

## Get campaign details

```http
GET /campaigns/:id
```

### Response

```json
{
  "data": {
    "id": "uuid",
    "keyword": "seo tools",
    "niche": "Digital Marketing",
    "target_domain": "myblog.com",
    "status": "active",
    "language": "en",
    "is_public": false,
    "public_share_token": null,
    "progress": { "phase": "analyze", "opportunities_found": 12 },
    "general_strategies": [],
    "websites": { "url": "https://example.com" }
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `target_domain` | string | The domain being researched for backlinks |
| `is_public` | boolean | Whether the campaign results are publicly shared |
| `public_share_token` | string | Token used to construct the public share URL |
| `progress` | object | Research job progress (phase and counts) |

## List campaign opportunities

```http
GET /campaigns/:id/opportunities
```

### Response

```json
{
  "data": [
    {
      "id": "uuid",
      "url": "https://target-site.com/article",
      "title": "Top SEO Tools Review",
      "strategy": "guest_post",
      "type": "blog",
      "relevance_score": 85,
      "domain_authority": 45,
      "domain_rating": 52,
      "monthly_traffic": "15K",
      "link_type": "dofollow",
      "niche_relevance": "high",
      "reasoning": "Highly relevant blog in the SEO space with active guest post program",
      "tags": ["guest-post", "high-da"],
      "status": "new",
      "contact_info": null
    }
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `relevance_score` | integer | AI-assessed relevance (0–100) |
| `domain_authority` | integer | Moz-style domain authority |
| `domain_rating` | integer | Ahrefs-style domain rating |
| `monthly_traffic` | string | Estimated monthly traffic for the page |
| `link_type` | string | Expected link type: `dofollow`, `nofollow`, `unknown` |
| `niche_relevance` | string | Qualitative relevance: `high`, `medium`, `low` |
| `reasoning` | string | AI explanation of why this opportunity was surfaced |
| `tags` | array | User-defined or auto-generated labels |
| `contact_info` | object | Discovered contact details (structured JSON) |

## Update an opportunity

```http
PATCH /opportunities/:id
```

### Request body

```json
{
  "status": "contacted",
  "contact_email": "editor@target-site.com",
  "contact_name": "John Doe",
  "outreach_status": "email_sent",
  "notes": "Sent initial outreach on Jan 15"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `status` | string | Opportunity status |
| `contact_email` | string | Contact email address |
| `contact_name` | string | Contact person name |
| `outreach_status` | string | Outreach progress status |
| `notes` | string | Free-text notes |

### Response

```json
{
  "success": true,
  "updated": { "status": "contacted", "contact_email": "editor@target-site.com" }
}
```

## Generate an outreach email

```http
POST /opportunities/:id/generate-email
```

Generates an AI-written personalized outreach email for the opportunity.

### Response

```json
{
  "data": {
    "opportunity_id": "uuid",
    "email_text": "Subject: Partnership Opportunity...\n\nHi,\n\n...",
    "email_html": "<p>Subject: Partnership Opportunity...</p>..."
  }
}
```

## Send an outreach email

```http
POST /opportunities/:id/send-email
```

### Request body

```json
{
  "to_email": "editor@target-site.com",
  "subject": "Partnership Opportunity — SEO Tools",
  "body_text": "Hi John,\n\nI'd love to collaborate...",
  "body_html": "<p>Hi John,</p><p>I'd love to collaborate...</p>"
}
```

| Field | Required | Description |
|-------|----------|-------------|
| `to_email` | Yes | Recipient email address |
| `subject` | Yes | Email subject line |
| `body_text` | Yes | Plain text email body |
| `body_html` | No | HTML email body |

<Warning>
  Organization SMTP settings must be configured under **Settings** before sending.
</Warning>

### Response

```json
{
  "success": true,
  "message": "Email queued for sending. Opportunity status updated to outreach_sent.",
  "data": { "opportunity_id": "uuid", "to_email": "editor@target-site.com", "subject": "..." }
}
```
