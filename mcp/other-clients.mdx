Any client that supports **remote (HTTP) MCP servers** can connect to Keupera.
Point it at the endpoint and authenticate with OAuth or an API key.

```
URL:  https://mcp.keupera.com/mcp
Auth: Sign in with Keupera (OAuth)  —or—  Authorization: Bearer sk_live_…
```

## Generic configuration

Most clients accept an MCP server entry like this:

```json
{
  "mcpServers": {
    "keupera": {
      "type": "http",
      "url": "https://mcp.keupera.com/mcp",
      "headers": {
        "Authorization": "Bearer sk_live_your_key"
      }
    }
  }
}
```

Omit `headers` if your client supports OAuth — it will prompt you to sign in on
first use.

## Popular clients

<AccordionGroup>
  <Accordion title="Cursor">
    Settings → **MCP** → **Add new MCP server** → choose an HTTP/remote server
    and enter `https://mcp.keupera.com/mcp`. Authorize when prompted, or add an
    `Authorization: Bearer sk_live_…` header.
  </Accordion>
  <Accordion title="VS Code (GitHub Copilot / MCP)">
    Add an MCP server of type **HTTP** with URL
    `https://mcp.keupera.com/mcp` in your MCP configuration, then authenticate.
  </Accordion>
  <Accordion title="Windsurf">
    Add a custom MCP server pointing to `https://mcp.keupera.com/mcp` and connect
    via OAuth or a Bearer API key.
  </Accordion>
</AccordionGroup>

<Note>
  Get API keys from **Settings → API Keys** in the
  [dashboard](https://app.keupera.com). Never embed a key in a browser app —
  keep it server-side.
</Note>

See the [tool reference](/mcp/tools) for everything you can do once connected.
